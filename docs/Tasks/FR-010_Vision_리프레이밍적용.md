> ### 🔄 SRS v3.0 반영 — 이 태스크에서 바뀐 것 *(2026-09-01)*
> 🔴 **리프레이밍의 위치가 정정됐다** — ③완성 단계가 아니라 **②트래킹의 Cutie 단계**다. 이 태스크는 둘로 나뉜다: **(A) 크롭 경로 확보**(Cutie 응답 수용 · 미제공 시 궤적에서 자체 산출) · **(B) 선택한 클립만 원본 해상도로 적용**(ADR-3 유지). 🔴 **강제 9:16 삭제** — 입력 방향을 유지한다.
>
> **기준 문서**: `SRS/[SRS]hilit-SRSv2.0-nextjs.md` **v3.0 §3.2 · §7.4** · `PRD/HILiT_PRD_v0_2.md` §4.1 · ADR-3 · `HILIT_추적PoC_기술기획서.md` §2.3 · §3.9

## 🎯 Summary
- 기능명: **[FR-010] 화면 구석에 작게 잡힌 사람을 화면의 주인공으로 만든다**
- 목적: **경로 산출과 고화질 적용을 분리해, 원가는 ADR-3을 지키고 품질은 Cutie 마스크를 쓴다.**

> 🔴 **경로 산출과 적용은 다른 시점이다.**
> ```
> ② Cutie 정밀 복구 ──→ cropPath 산출 (저해상도 · 복구 대상 구간)
> ③ 사용자 선택 ─────→ 고른 클립만 원본 해상도로 적용 (ADR-3)
> ```
> 이 분리가 없으면 **선택하지 않을 클립까지 고화질 처리**해 ADR-3이 무너진다.

> 🔴 **정상 구간의 크롭 경로는 어디서 오는가.** Cutie는 **불확실 구간에만** 돈다. 정상 구간은 브라우저 추적 궤적(`bboxTimeline`)에서 **이 태스크가 산출**한다. **두 출처의 경로가 한 클립 안에서 이어져야 한다** — 이음매에서 화면이 튀면 O3(구도 만족도)가 깨진다.

> 🔴 **강제 9:16을 걷어냈다.** PoC §2.3: *"가로 영상을 세로로 억지로 자르지 않는다. 16:9 / 9:16 / 1:1 / 4:5는 사용자가 명시적으로 고르는 export 옵션일 때만 적용된다."*

## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 경로가 Cutie 단계에서 나온다**
- **Given**: 불확실 구간이 복구된 클립
- **When**: 복구 webhook을 수신함
- **Then**: 🔴 **`crop_path` 가 `person_tracks` 에 저장된다.** 선택 이후에 다시 마스크를 만들지 않는다

**Scenario 2: 정상 구간에도 경로가 있다**
- **Given**: 복구가 한 번도 일어나지 않은 클립(전 구간 정상)
- **When**: 크롭 경로를 조회함
- **Then**: 🔴 **브라우저 궤적에서 산출된 경로가 있다.** Cutie를 부르지 않고도 리프레이밍이 성립한다

**Scenario 3: 두 출처의 경로가 이어진다**
- **Given**: 한 클립 안에 정상 구간 + 복구 구간
- **When**: 결과 영상을 확인함
- **Then**: 🔴 **이음매에서 화면이 튀지 않는다.** 두 경로를 스무딩으로 연결한다

**Scenario 4: 선택하지 않은 클립은 고화질 처리되지 않는다** *(ADR-3)*
- **Given**: 후보 10개 중 3개 선택
- **When**: 렌더를 실행함
- **Then**: 🔴 **3개만 원본 해상도로 처리된다.** 10개를 전부 처리하면 **쓰이지 않을 처리비가 버려진다**

**Scenario 5: 가로 영상이 세로로 강제되지 않는다** *(PoC §2.3)*
- **Given**: 16:9 가로 원본
- **When**: 비율을 지정하지 않고 완성함
- **Then**: 🔴 **가로로 출력된다.** 9:16은 사용자가 고를 때만 적용된다

**Scenario 6: 좌표계가 하나다**
- **Given**: Cutie 경로와 자체 산출 경로
- **When**: 저장 형식을 확인함
- **Then**: 🔴 **둘 다 클립 기준 0~1.** 원본 좌표로 섞이면 오프셋 계산이 사방에 퍼진다

**Scenario 7: 확대 배율이 화질 임계를 넘지 않는다**
- **Given**: 인물이 매우 작게 잡힌 구간
- **When**: 리프레이밍을 적용함
- **Then**: **배율 상한에서 멈추고 그 사실이 계측된다.** 🔺 O3를 **촬영 거리 조건부**로 재정의하는 근거가 된다(PRD G2)

**Scenario 8 (실패): 경로 산출을 선택 이후로 미루지 않는다**
- **Given**: "선택된 것만 경로를 만들면 더 싸지 않나" 라는 검토
- **When**: 설계를 판단함
- **Then**: 🔴 **Cutie 마스크는 복구 시점에만 존재한다.** 선택 이후로 미루면 **마스크를 다시 만들어야 하고 복구를 두 번 호출**하게 된다 — 더 비싸다
