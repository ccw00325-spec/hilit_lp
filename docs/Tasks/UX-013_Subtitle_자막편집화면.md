> PRD v0.2 F18b. 🔴 **REQ-FUNC-026이 `Won't Have` → `Must Have` 로 승격**되면서 화면이 필요해졌다.

## 🎯 Summary
- 기능명: **[UX-013] 편집 실력 없이도 자막이 붙는다**
- 목적: **정민수(B-2)의 "컷·자막·음악까지 30분 넘어 중도 포기" 를 자막에서 끊는다.**

> 🔴 **자막은 마지막 단계다.** 여기서 30분이 걸리면 앞의 모든 자동화가 무의미해진다. **입력 최소화가 설계 목표**다.

> 🔴 **무료 티어에 있다.** 결제 유도를 위해 여기에 제한을 걸지 않는다 — 무료로도 완성까지 가야 한다(AC7-1).

> 🔴 **OFL 고지가 화면 요구사항이다.** 폰트 5종 표기 의무를 앱 안에서 지킨다(AC7-2). 설정 깊숙이 숨기지 않는다.

## 🧪 설계 인수 기준

**Scenario 1: 자막 없이도 끝난다**
- **Given**: 자막 화면
- **When**: 건너뛰기를 선택함
- **Then**: **완성으로 진행된다.** 자막이 필수 관문이 되면 정민수는 여기서 또 포기한다

**Scenario 2: 미리보기가 즉시 반영된다**
- **Given**: 자막 텍스트를 입력 중
- **When**: 타이핑함
- **Then**: **프리뷰에 즉시 보인다.** 저장 후에야 확인되면 왕복이 늘어난다

**Scenario 3: 폰트가 실제로 보인다**
- **Given**: 폰트 선택
- **When**: 5종을 훑음
- **Then**: 🔴 **미리보기가 실제 폰트로 렌더된다.** 이름만 보고 고르게 하지 않는다

**Scenario 4: 타임코드를 타이핑하지 않아도 된다**
- **Given**: 자막 타이밍 조정
- **When**: 타임라인을 스크러빙함
- **Then**: **시작/종료가 설정된다.** 숫자 입력은 보조 수단이다

**Scenario 5: OFL 고지가 가깝다** *(AC7-2)*
- **Given**: 자막 화면
- **When**: 라이선스 정보를 찾음
- **Then**: 🔴 **1탭 거리에 5종이 전부 명시**되어 있다. 설정 깊숙이 숨기면 표기 의무를 형식적으로만 지킨 것이다

**Scenario 6: 결과가 미리보기와 같다**
- **Given**: Pretendard로 설정
- **When**: 렌더 결과를 확인함
- **Then**: 🔴 **같은 폰트다.** `document.fonts.ready` 대기가 없으면 대체 폰트로 구워진다(FR-039)

**Scenario 7: 무료 사용자가 제한받지 않는다**
- **Given**: 무료 플랜
- **When**: 자막을 편집함
- **Then**: **폰트 5종·스타일 전부 사용 가능하다**

**Scenario 8 (실패): 자동 자막 생성을 이 화면에 넣지 않는다**
- **Given**: "음성 인식으로 자동 생성하면 좋겠다" 는 요구
- **When**: 범위를 검토함
- **Then**: 🔴 **PRD v0.2 F18b는 "편집"이다.** 자동 생성은 요구사항에 없으며, 추가하려면 **PRD 개정이 먼저**다 — 외부 STT 의존·원가·게이트가 새로 생긴다
