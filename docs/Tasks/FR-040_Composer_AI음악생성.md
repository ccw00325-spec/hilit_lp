> 🔴 **이 태스크는 개발이 끝나도 배포되지 않을 수 있다.** `MUSIC_LICENSE` 미승인이면 빌드에서 이 경로가 제거된다. 🟢 **다행히 음악은 건너뛸 수 있는 단계이고, 무료 라이브러리(FR-015)가 폴백으로 있다.**

## 🎯 Summary
- 기능명: **[FR-040] 영상에 맞는 곡을 만들어 준다**
- 목적: **앱 밖으로 나가지 않고 완성한다는 조건을 음악 생성에도 지킨다.**

> 🔴 **소비 단위는 "생성"이 아니라 "채택"이다.** 1회 생성에 **2곡**이 나오고 사용자가 그중 하나를 고른다(AC7-4). 한도를 "생성 횟수"로 표기하면 **재생성할 때마다 손해를 보는 것처럼 읽힌다** — 잔여를 **생성 전에** 보여준다.

> 🔴 **후차감이다.** 생성 실패·제공자 장애 시 차감하지 않는다(AF-11). 선차감 후 환불 로직을 만들면 **경계 조건이 배로 늘어난다.**

> 🔴 **소진이 벽이 되면 안 된다.** 한도를 다 쓰고도 쓸 곡이 없으면 **무료 라이브러리(FR-015)로 자연스럽게 넘긴다**(AF-12). 음악 없이 끝내게 하거나 결제만 남기지 않는다.

## 🧪 Acceptance Criteria (BDD/GWT)

**Scenario 1: 1회에 2곡이 나오고 하나를 고른다** *(AC7-4)*
- **Given**: 잔여 3회인 구독 사용자
- **When**: 생성을 실행함
- **Then**: **2곡이 제시되고 하나를 선택**한다. 사용량은 **1회** 줄어든다

**Scenario 2: 생성 전에 잔여가 보인다** *(AC7-4)*
- **Given**: 잔여 1회
- **When**: 생성 화면에 진입함
- **Then**: 🔴 **"남은 생성 1회" 가 버튼을 누르기 전에 보인다.** 누른 뒤에 알면 손해로 읽힌다

**Scenario 3: 실패가 차감되지 않는다** *(AF-11)*
- **Given**: Suno 장애
- **When**: 3회 재시도 후 실패함
- **Then**: 🔴 **잔여가 그대로다** · 무료 라이브러리 경로가 제시된다

**Scenario 4: 소진이 벽이 되지 않는다** *(AF-12)*
- **Given**: 3회를 다 썼는데 쓸 곡이 없음
- **When**: 완성을 진행함
- **Then**: 🔴 **무료 라이브러리로 자연스럽게 넘어간다.** 결제 버튼만 남기지 않는다

**Scenario 5: 채택률이 계측된다** *(Q17)*
- **Given**: 생성 5회 · 실제 사용 2회
- **When**: 지표를 조회함
- **Then**: 🔴 **`music_ai_applied ÷ music_generated` 가 나온다.** **PRD Q17(한도 3회가 충분한가)을 푸는 유일한 계측점**이다

**Scenario 6: 게이트 미승인 시 기능이 빌드에 없다**
- **Given**: `MUSIC_LICENSE` 가 `PENDING`
- **When**: 빌드를 수행함
- **Then**: 🔴 **AI 음악 라우트가 번들에서 제거된다.** 무료 라이브러리도 같은 게이트에 걸리므로 **음악 단계 전체를 건너뛰는 경로**가 살아 있어야 한다

**Scenario 7: 생성곡이 라이브러리 곡과 구분된다**
- **Given**: `origin = AI` 인 곡
- **When**: 조회함
- **Then**: **`LIBRARY` 와 구분된다.** 라이선스 판정·회수가 출처별로 다를 수 있다

**Scenario 8 (실패): 선차감 후 환불로 만들지 않는다**
- **Given**: "먼저 빼고 실패하면 돌려주자" 라는 검토
- **When**: 설계를 판단함
- **Then**: 🔴 **후차감으로 간다.** 환불 경로는 부분 실패·중복 webhook·타임아웃에서 **경계 조건이 배로 늘어난다**

## ⚙️ Technical & Non-Functional Constraints
- 🔴 **후차감** — 성공 확정 후에만 `UsageLedger` 기록
- 🔴 **AI SDK 밖** — 어댑터로 감싸 교체 가능성만 유지
- 🔴 **생성이 길면 비동기** — A-T1 · webhook 수신
- 🔺 **추가 사용분 단가 미정**(Q18) — 설정값으로 분리 · 🔴 **무료(선불)와 구독(후불)이 같은 단가일지도 미정**
- 🔴 **접근 판정을 플랜으로 하지 않는다** — `remaining > 0`. 🔴 **다른 기능으로 일반화 금지**(무료에 AI 컷이 열린다)
- 🔴 **"소진" 문구가 플랜별로 다르다** — 구독은 **종량으로 넘어가고**, 무료는 **거기서 끝난다**

- 결과물 길이 자동 맞춤은 FR-015와 **같은 규칙**을 쓴다
